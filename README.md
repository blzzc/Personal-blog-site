# ORBITAL LOG · 轨道日志

一个复古未来风的个人图文博客。访客可以按分类读日志，或在影像集中浏览配图。主页中的三篇示例会在发布第一篇日志后自动隐藏。

## 在 GitHub Pages 上发布

在仓库的 **Settings → Pages** 中，将 **Source** 设为 **Deploy from a branch**，选择 **main → /docs** 并点击 **Save**。构建好的站点在 `docs/` 目录，无需额外配置构建。部署完成后，Pages 设置页会显示访问地址。

## 写作与发布

1. 点击 **写日志**，添加标题、正文和图片。用 **加文字** 在图片后继续写。每篇支持最多 6 张 JPG、PNG、WebP 或 GIF 图片，每张上限 8 MB。
2. 点击 **保存草稿**。草稿只保存在当前浏览器，可在顶部的 **草稿** 中重新打开、编辑和删除。
3. 打开要发布的草稿，点击 **导出发布文件**。下载的 `posts.json` 包含选中的草稿、配图和当前网站已发布的日志。
4. 在 GitHub 仓库打开 `docs/`，选择 **Add file → Upload files**，上传同名 `posts.json` 并提交到 `main`。Pages 会更新公开日志。连续发布多篇时，等网站显示上一篇后再导出下一篇。

在网页上打开已发布的日志，也可以点击 **编辑日志**，将修订保存为草稿后重新导出发布。导出文件上限为 25 MB。

## 本地运行

使用 Node.js 22.12+ 或 20.19+。

```sh
npm ci
npm run dev
npm run build
```

`npm run build` 会更新 `docs/` 下的站点文件，保留 `docs/posts.json`。示例影像是为本站生成的。
